# NeoDent — V0 Design Reference

Use this file as the visual/design source of truth when generating new NeoDent frontend sections.

## Canonical style
Section 02 — “Decades of changing smiles.” — is the PRIMARY reference.
Do not copy its exact layout. Inherit its visual language.

## Mandatory DNA
- premium editorial healthcare
- warm ivory + deep charcoal
- NeoDent red for emphasis
- consistent oversized chapter numbers 01, 02, 03, 04...
- consistent small tracked eyebrow labels
- controlled serif/sans typography hierarchy
- serif red emphasis for selected phrases
- restrained but meaningful body copy
- thin drafting/registration lines
- subtle crosshair/geometric marks
- precise image framing
- editorial metadata
- smooth restrained motion
- intentional responsive re-composition

## Golden rule
Every new section must feel like it was designed by the SAME ART DIRECTOR as Section 02.

Do not invent a new typography scale, chapter-number treatment, eyebrow treatment, spacing rhythm, or color language for each section.

## Section-specific freedom
Keep the shared system, but vary composition:
- Section 02 = legacy/archive/documentary
- Section 03 = treatment/clinical evidence/drafting
- Section 04 = clinical leadership/people/portrait
- later sections = same system, new editorial composition

## Content
Balance visual storytelling with useful NeoDent context. Do not add filler. Use only verified project content.

## Motion
Prefer reveal, fade, slide, stagger and clip/image reveal. Avoid bounce, gimmicks and excessive parallax.

## Responsive
Design intentionally for 390 / 430 / 768 / 1024 / 1280 / 1440.

## Reuse
Reuse existing NeoDent components and patterns where practical. Do not redesign approved sections unless explicitly requested.
